KEY RELATIONSHIP

VPC → spans Region
Subnet → belongs to one AZ
AZ → can contain multiple subnets

KEY NETWORKING COMPONENTS

Route Table → decides where traffic goes.
Internet Gateway → connects VPC to Internet.
NAT Gateway → private resources → Internet outbound.
Load Balancer → distributes traffic among servers.

================ DAY 26 — NETWORK PORTS ================

HANDS-ON PRACTICE

1. CHECK LISTENING PORTS

Command:

ss -tuln

Purpose:

Displays listening TCP and UDP sockets without process
information.

Observed:

The system displayed listening network sockets along with
their local addresses and port numbers.


2. CHECK LISTENING PORTS WITH PROCESS INFORMATION

Command:

sudo ss -tulnp

Purpose:

Displays listening TCP and UDP sockets along with the
associated process name and PID.

The normal command:

ss -tulnp

did not show process names.

Running it with sudo provided the required process information.

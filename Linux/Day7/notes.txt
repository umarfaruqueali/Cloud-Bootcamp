Revision + OverTheWire Bandit (Levels 0-5)

New Commands Learned

find:
- find .                 -> Find all files and directories
- find . -type f         -> Find only files
- find . -size 1033c     -> Find files of exactly 1033 bytes
- find . -exec file {} \; -> Run 'file' command on every file found

file:
- file filename          -> Identify the type of a file

ls:
- ls -a                  -> Show hidden files
- ls -l                  -> Show detailed information
- ls -la                 -> Show hidden files with details

Concepts Learned

- Hidden files begin with '.'
- File names can contain spaces.
- File names can begin with '-'.
- File type can be identified using the file command.
- The find command can search files using different filters.

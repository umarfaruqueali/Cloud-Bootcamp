# Linux

This section contains Linux notes, commands, hands-on practice, and mini-projects completed during the Cloud Engineering Bootcamp.

## Topics Covered

- Linux fundamentals
- Files and directories
- Users, groups, and permissions
- Processes and system management
- Package management
- Bash scripting
- Cron jobs
- Logs and environment variables
- SSH and SCP
- Linux troubleshooting

## Structure

Each learning day contains:

- `commands.txt` — commands practiced during the session
- `notes.txt` — concepts and explanations
- `practice.txt` — hands-on practice and observations

Some days also contain scripts and practical project files.

## Practical Work

The Linux module includes hands-on exercises covering:

- File and directory management
- Permissions and user management
- Bash scripts
- Automated tasks with cron
- Log and environment variable handling
- Backup and system health-check scripts
- SSH/SCP practice
- Linux troubleshooting

## Learning Goal

Build a strong Linux foundation for cloud engineering, DevOps, automation, and server administration.

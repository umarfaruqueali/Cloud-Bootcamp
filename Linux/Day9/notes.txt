Day 9


========


What is a Process?
- A process is a running program.
- Example: Firefox, VS Code, ping.

What is a Service?
- A service is a background process.
- It provides functionality to the operating system.
- Examples: cron, Bluetooth, Wi-Fi, SSH.

What is systemd?
- systemd is the service manager in Linux.
- It starts, stops and manages services during boot and runtime.

What is systemctl?
- systemctl is the command-line tool used to communicate with systemd.

Important Commands

systemctl list-units --type=service
- Shows currently loaded/running services.

systemctl status <service>
- Shows detailed information about a service.

systemctl is-active <service>
- Checks whether the service is currently running.

systemctl is-enabled <service>
- Checks whether the service starts automatically during boot.

systemctl list-unit-files --type=service
- Lists all installed service files.

Important States

loaded
- Service configuration has been loaded.

active
- Service is currently active.

running
- Service is actively running.

enabled
- Service starts automatically during boot.

disabled
- Service does not start automatically.

static
- Service cannot be enabled manually; it starts when required by another service.

masked
- Service is blocked from starting.

Today's Learning
- Every service is a process.
- Not every process is a service.
- systemd manages Linux services.
- systemctl is used to interact with systemd.

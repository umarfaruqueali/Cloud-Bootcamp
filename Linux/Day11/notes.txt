======== Day 11 : SSH ========

SSH :
- SSH (Secure Shell) is a secure protocol used to connect to remote computers.

WHY SSH?
- Encrypted communication.
- Password-less login using keys.
- Used for GitHub, AWS EC2 and Linux servers.

SSH KEY PAIR

1. Private Key
- Stored as id_ed25519.
- Never share it.

2. Public Key
- Stored as id_ed25519.pub.
- Safe to share with servers.

COMMANDS

1. ssh
   - Shows SSH usage.

2. ssh -V
   - Displays SSH version.

3. which ssh
   - Shows SSH executable location.

4. ssh-keygen
   - Generates SSH key pair.

5. ls -la ~/.ssh
   - Lists SSH files.

6. cat ~/.ssh/id_ed25519.pub
   - Displays public SSH key.

7. ssh -T git@github.com
   - Tests GitHub authentication.

8. git remote -v
   - Displays Git remote URL.

Summary:
Today I learned how SSH works, how SSH keys authenticate securely, and how GitHub uses SSH instead of passwords.

#DAY 55 # — Module 4B Revision + Apache Website Deployment

CONCEPT
- EC2: virtual server in AWS.
- Apache: web-server software installed on Ubuntu; receives HTTP requests and serves website files.
- HTML: defines the webpage content and structure.
- Security Group: virtual firewall controlling allowed inbound/outbound traffic.
- HTTP uses TCP port 80. HTTPS uses TCP port 443 and requires TLS configuration.
- SSH uses TCP port 22. Restrict SSH source to a trusted/current public IP, typically /32.
- Public IPv4 can change after stop/start unless a retained address is configured.
- Stopping EC2 generally stops compute charges, but attached EBS storage charges continue; public IPv4 charges may also apply.

DEPLOYMENT PATH
Browser -> public IPv4:80 -> Security Group inbound rule -> EC2 Ubuntu -> Apache -> /var/www/html/index.html
Apache was enabled with systemctl enable --now apache2.

IMPORTANT COMMANDS
- aws ec2 describe-instances ... : inspect instance state/IP (read-only).
- aws ec2 describe-security-groups ... : inspect Security Group rules (read-only).
- ssh -i KEY ubuntu@PUBLIC_IP : connect to Ubuntu EC2.
- sudo apt update : refresh package index.
- sudo apt install apache2 -y : install Apache.
- sudo systemctl enable --now apache2 : enable/start Apache.
- systemctl is-active apache2 : check Apache status.
- sudo tee /var/www/html/index.html ... : write the HTML homepage.
- curl -I http://localhost : inspect HTTP response headers.
- curl http://localhost : inspect returned HTML.
- aws ec2 stop/start/describe-instances : stop/start/inspect an EC2 instance; stop/start changes state and may affect cost.

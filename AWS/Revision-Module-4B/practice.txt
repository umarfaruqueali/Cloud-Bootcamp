14. Stopped the EC2 instance after the successful browser test.

RESULT
The website was successfully deployed on the existing EC2 instance and verified both locally with curl and externally in a browser. Apache was active during testing. The instance was stopped after the test to limit compute charges.

COST AND SECURITY NOTES
- No new EC2 instance, AMI, EBS volume, or Elastic IP was created for this project.
- Compute charges generally stop when an EC2 instance is stopped, but attached EBS storage charges continue; public IPv4 charges may apply.
- HTTP is unencrypted and was used only for this basic demonstration.
- SSH was restricted to a specific source IP, not 0.0.0.0/0.
- The HTTP inbound rule was added. Remove it if public access is not needed until the next practice session.
- Confirm the final instance state in AWS CLI/Console before considering cleanup complete.

CONCLUSION
Practised basic EC2 web hosting: start and inspect an instance, troubleshoot SSH source-IP restrictions, install Apache, create an HTML page, allow HTTP traffic, verify the page from the server and browser, and stop the instance afterward.

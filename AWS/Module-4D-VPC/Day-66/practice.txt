5. Observations
- AWS automatically creates a main route table.
- AWS automatically adds a local route for the VPC CIDR.
- Creating a VPC only does not create subnets or an Internet Gateway.
- A route table decides the next hop; an Internet Gateway provides VPC internet connectivity.

## IAM Group Practice

Ran:

aws iam list-groups

Result:

Administrators
ReadOnlyUsers

Ran:

aws iam get-group --group-name Administrators

Result:
Administrators group details and cloud-admin user returned.

Ran:

aws iam list-groups-for-user --user-name cloud-admin

Result:
cloud-admin belongs to Administrators.

Ran:

aws iam get-group --group-name ReadOnlyUsers

Result:
ReadOnlyUsers exists but currently has no users.

## IAM Policy Practice

Ran:

aws iam list-attached-group-policies --group-name Administrators

Result:
AdministratorAccess found.

Ran:

aws iam list-attached-group-policies --group-name ReadOnlyUsers

Result:
CloudBootcamp-S3-ReadOnly found.

Ran:

aws iam get-policy --policy-arn arn:aws:iam::aws:policy/AdministratorAccess

Result:
AdministratorAccess policy metadata returned.

DefaultVersionId:
v1

Ran:

aws iam get-policy-version --policy-arn arn:aws:iam::aws:policy/AdministratorAccess --version-id v1

Result:
Actual policy document returned.

Observed:

Effect = Allow
Action = *
Resource = *

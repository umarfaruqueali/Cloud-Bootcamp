## Key Observation

AZ names and AZ IDs do not always follow the same numbering order.

Mumbai:
a → az1
b → az3
c → az2

Hyderabad:
a → az1
b → az2
c → az3

Singapore:
a → az2
b → az1
c → az3

This demonstrates why AZ IDs should be treated as the stable identifiers rather than assuming the AZ letter corresponds to the AZ ID number.

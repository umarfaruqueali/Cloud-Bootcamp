## JOB-STYLE TROUBLESHOOTING

Problem:
AWS CLI command fails.

Check:

1. Is AWS CLI installed?
   → aws --version

2. Is CLI configured?
   → aws configure list

3. Which AWS identity is being used?
   → aws sts get-caller-identity

4. If credentials are missing/invalid:
   → Check credential/profile/environment configuration.

5. If authentication works but operation fails:
   → Check IAM permissions.
